BALL SPLITTER - iPhone Web App

This package is a Progressive Web App (PWA), not a compiled IPA.

To install on iPhone:
1. Host these files on an HTTPS website (for example, GitHub Pages).
2. Open the website in Safari on your iPhone.
3. Tap Share -> Add to Home Screen -> Add.

The game includes an automatically rotating sword, adjustable speed, ball splitting, a breakable inner ring, and a 200,000-ball target.

Note: For smooth performance, the game simulates all balls but visually renders a sample when the count becomes very large.
